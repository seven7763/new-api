如何开始使用？

注册 → 钱包充值 → 创建密钥并选分组 → 配置 Base URL 与密钥到客户端。

Base URL 怎么填？

401 / 密钥无效？

检查 sk 是否完整、是否已删除/禁用、Header 是否为 Bearer sk-...、Base URL 是否指向本站。

403 / 分组不可用？

密钥分组与模型不匹配、余额不足或策略限制。更换分组/充值后重试。

429 限流？

降低并发，加重试退避；高峰错峰或升级配额。

502 / 503 / 超时？

切换直连线路 jp.daoxe.com，开启客户端重试，降低 max_tokens 或拆分任务。
