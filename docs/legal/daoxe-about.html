我们提供什么

API

统一接口

兼容 OpenAI 接口规范，并支持 Claude Messages 等多协议格式，迁移几乎零改动。

HUB

多模型聚合

汇聚 OpenAI、Anthropic、Google、Mistral、xAI 及主流国产大模型，一处密钥，多模型可用。

HA

多线路与故障转移

同一模型可配置多条上游线路，异常自动切换，尽力保障调用连续性。

PAY

按量计费与配额

以 Token 等用量计量、按量结算，无套餐绑定；支持分组配额与令牌额度管理。

LOG

用量日志与看板

提供调用日志、用量统计与数据看板，消费与用量清晰可查、便于对账。

SEC

密钥与安全

传输层 TLS 加密、令牌隔离、最小化数据留存；不主动存储对话正文。
