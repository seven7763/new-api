服务范围声明

DaoXE 是一个面向全球开发者的境外 AI 服务接入平台， 不向中华人民共和国大陆地区（不含香港、澳门、台湾）用户提供任何形式的服务。 本《隐私政策》仅适用于已合法访问本服务的境外用户， 不构成对中国大陆地区任何主体的服务承诺或法律承诺。

核心隐私承诺

本服务不主动存储您的对话正文。AI 请求与响应在转发完成后即被丢弃， 仅保留必要的元数据（请求时间、Token 用量等）用于计费与排障。我们遵循最小必要原则 收集与处理您的信息。

本《隐私政策》适用于 DaoXE（daoxe.com，以下简称「本服务」或「我们」） 提供的所有产品与服务，说明我们如何收集、使用、存储、共享您的信息，以及您所拥有的权利。

当您使用本服务时，即表示您已阅读并理解本政策。本服务为境外 AI 服务接入平台， 不向中国大陆地区用户提供服务，详见 《用户服务协议》。

02

我们收集的信息

我们仅收集为提供和改进服务所必需的最少信息，具体包括：

信息类型 具体内容 必要性
账户信息 邮箱地址、用户名、密码（单向哈希存储） 必须
API 凭证 系统为您生成的 API Key（服务端受控存储） 必须

03

信息使用目的

我们使用收集的信息用于：

  • 提供服务：验证身份、路由请求至上游模型、扣费结算
  • 账户管理：登录、密码重置、安全通知
  • 服务改进：基于聚合数据统计模型使用分布、优化性能
  • 风险控制：检测异常调用、滥用、欺诈，保护账户安全
  • 客户支持：响应您的咨询、工单、投诉
  • 合规要求：履行适用法律法规规定的义务
04

第三方共享与上游数据流向

我们不出售您的个人信息。仅在以下情形向第三方传输必要信息：

  • AI 模型服务商：为完成您的请求，我们会将 请求内容（对话 / Prompt）转发给 OpenAI、Anthropic、Google、 Mistral 等上游服务商。这些服务商按其自身隐私政策处理数据，本服务无法控制其留存与使用方式。
  • 支付处理方：充值时，支付信息由独立的支付服务商处理（如 Stripe、加密货币网关等）， 我们通常仅接收支付结果与订单号。
  • 云基础设施：服务部署于境外云服务商，数据传输与存储受其安全机制保护。
  • 法律要求：在收到合法、有效的司法或行政机关请求时，我们可能依法披露必要信息。
重要提醒： 您输入的内容会被上游模型服务商接收并按其政策处理（部分服务商可能用于安全审核或模型改进）。 请避免向 AI 输入敏感、隐私或机密信息。
05

数据存储与安全

  • 存储位置：所有数据存储于境外服务器，不在中国大陆境内
  • 传输加密：用户与本服务之间采用 HTTPS / TLS 加密传输
  • 凭证保护：登录密码采用业界标准的单向哈希算法（如 bcrypt）存储，无法逆向还原；API Key、访问令牌等在服务端受控存储并施加访问控制
  • 访问控制：遵循最小权限原则，关键操作保留必要的操作与审计记录

数据保留期限（示意，最终以实际运营配置为准）：

对话正文 不主动存储
使用元数据 按运营需要保留
账户信息 注销后合理期限内删除
计费记录 依据财务与法律要求
06

Cookie 与本地存储

本服务使用必要的 Cookie 与浏览器本地存储（localStorage / sessionStorage）以维持登录状态与用户偏好，具体包括：

  • 认证信息：维持登录会话（登出或过期后失效）
  • 偏好设置：主题、语言、侧栏折叠等界面偏好
  • 不使用第三方广告追踪 Cookie

您可通过浏览器设置清除 Cookie 与本地存储，但可能影响部分服务功能。
